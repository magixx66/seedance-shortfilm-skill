# Quality checklist

## 故事与事实

- [ ] 每个镜头都有明确的剧情目的。
- [ ] 开场、转折和结尾能用一句话说清。
- [ ] 历史或现实信息已经核实，虚构和重构已标明。
- [ ] 总时长等于目标时长，时间轴没有重叠或空档。

## 镜头可生成性

- [ ] 每镜只有一个主动作。
- [ ] 每镜只有一个主运镜，或明确固定机位。
- [ ] 景别、构图、运动方向、速度和终点清楚。
- [ ] 抽象情绪已经改成可见表演。
- [ ] 复杂事件已经拆镜，而不是堆进一个提示词。

## 参考与连续性

- [ ] 每个 @参考 都写明参考属性。
- [ ] 人物外貌、年龄、发型、服装、道具和声线已锁定。
- [ ] 场景布局、时间、天气、光向和主色已锁定。
- [ ] 上一镜退出状态与下一镜入口状态一致。
- [ ] 屏幕方向、视线和动作阶段连续。

## 灯光与声音

- [ ] 灯光写明光源、方向、质感、色温和明暗关系。
- [ ] 色彩变化有剧情理由。
- [ ] Ambient、Foreground SFX、Music、Silence 已分别考虑。
- [ ] 关键声响不会被音乐和环境声淹没。

## 平台与交付

- [ ] 实际生成前已核对当前模型、时长、画幅、输入和政策限制。
- [ ] 精确文字、字幕、日期和标牌已安排到后期。
- [ ] 参考素材具备使用权或用户已获授权。
- [ ] 没有任何规避审核、身份保护或安全过滤的做法。
- [ ] 输出包含生成顺序、命名方式和失败后的最小修复路径。
