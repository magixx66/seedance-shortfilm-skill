# Continuity lock templates

连续性采用三层继承结构，避免跨场次切换时把不该锁死的天气/灯光也一并锁死，也避免在每个镜头重复堆砌全部设定：

1. **Project Bible（全片不变）**：画幅、摄影介质、核心色彩语言、角色逻辑 ID 的固定外貌与声线。
2. **Scene Lock（单场不变，如 `S01` / `S02`）**：本场地点布局、时间天气、本场服装道具、主光方向与默认屏幕方向。
3. **Shot Delta（单镜变化，如 `S01-01`）**：仅描述本镜独有的动作增量、机位运镜与出入镜状态。

## 1. Project Bible（全片级锁定）

    【Project Bible】
    项目画幅与帧率基线：
    摄影介质与质感：
    全片色彩语言：
    人物锁定（CHAR_01 / CHAR_02...）：
      - 逻辑 ID / 姓名 / 年龄与体态：
      - 固定面部、发型与显著特征：
      - 固定声线与语速风格：
    全片不允许变化：

## 2. Scene Lock（单场级锁定）

    【Scene Lock｜场次 S01】
    场景逻辑 ID 与布局（LOC_01）：
    时代/年代与物理边界：
    时间与天气：
    本场人物服装与随身道具（CHAR_01）：
    主光光源、方向与色温：
    本场辅助色与空气介质：
    默认屏幕方向与 180° 轴线基准：
    本场不允许变化：

跨场次（如从 `S01 雨夜站台` 切到 `S02 暖光室内`）时，**继承同一份 `Project Bible`**，只更新新场次的 `Scene Lock`，并写明角色服装/湿润度/道具变化的原因。

## 3. Shot Delta（镜头级控制）

    【Shot Delta｜S01-01】
    剧情目的：
    时长与剪辑余量（Handles）：
    本镜主动作：
    本镜景别与机位：
    本镜主运镜：
    进入状态：
    结束状态：
    本镜允许变化：
    与上一镜接力 → 向下一镜交接：

Shot Delta 写在 **Shot Card（导演控制卡）** 中管理，**不要直接把 `【Shot Delta】` 标题和交接说明塞进 Copy-ready Prompt 正文**。

## 4. 全局与单镜生成约束

    【全局约束】
    保持人物身份、服装、场景结构、画幅和摄影质感统一；画面中不出现无关路人、水印、现代穿帮物或随机文字。

    【本镜约束】
    <仅写与本镜高概率失败相关的 1–3 条限制，例如：右手始终握透明雨伞；人物保持从左向右移动；不切回全景。>

负面约束过多会稀释主要动作描述。

## 5. 图片编辑的修改与保留

    【只修改】
    将外套颜色改为深蓝色，保留原有材质和褶皱。

    【必须保持】
    人物面部、年龄、发型、表情、姿势、身体比例、摄影机角度、
    背景布局、光线方向和画幅完全不变。

    【避免】
    不改变衣服版型，不增加配饰，不磨平皮肤纹理。

连续多轮编辑时，每轮重新写出必须保持的项目，不要只说“其他不变”。

## 7. 示例：雨夜车站（S01）

    【Project Bible】
    画幅 16:9；写实电影摄影质感，保留自然暗部颗粒与湿润材质纹理；
    低饱和冷灰基调配克制局部暖光点；
    CHAR_01（林夏）：28 岁女性，齐耳短黑发，清瘦肩线，克制低声语调；
    全片不可变：人物五官、年龄感、短发长度、写实电影质感。

    【Scene Lock｜S01】
    LOC_01：老火车站二号站台，长椅在站台左侧偏中，尽头向右延伸；
    夜晚持续小雨，地面有真实积水反光；
    CHAR_01 本场穿米色旧风衣、深蓝围巾，右手握透明长柄雨伞；
    主光为站台顶部偏左冷白日光灯，右后方站台尽头有一盏微弱橙色信号灯；
    默认屏幕方向：CHAR_01 从画面左侧向右移动，视线朝右；
    本场不可变：雨伞手别（右手）、风衣围巾样式、冷白主光左上方来向。

    【Shot Delta｜S01-03】
    时长 5 秒（有效动作 0.5s–4.3s，首尾留余量）；中景。
    CHAR_01 从画面左侧走入，在长椅前停步并转头看向画面右侧站台尽头。
    摄影机缓慢侧向跟拍并在她停步时停稳。
    结束时位于画面中央偏左，右手仍握伞，视线锁定右方。
