# Prompt templates

## 单镜头简版

    【目标】
    生成一个 [时长]、[画幅] 的 [用途/情绪] 镜头。

    【画面】
    [主体] 在 [具体场景与空间位置] 完成 [一个主动作]。
    [景别]，[一个主运镜，含方向、速度和终点]。
    光线来自 [光源和方向]，[明暗与色温]；整体为 [色彩基调与质感]。
    人物通过 [可见身体反应] 表现 [情绪]。

    【声音】
    Ambient：[环境底噪]
    Foreground SFX：[动作声]
    Music：[配乐或无]
    Silence：[静音设计或无]

    【参考与连续性】
    [@素材]：只参考 [明确属性]，不参考 [容易混淆的属性]。
    Continuity Lock：[人物、服装、道具、场景、光向、色彩、屏幕方向]。
    Shot Delta：[本镜允许变化的动作、构图、机位与结束状态]。
    与上一镜接力：[入口状态]；向下一镜交接：[出口状态]。

    【约束】
    一个主动作，一个主运镜；不添加额外人物、文字或无关事件。

## 参考素材清单

    @图片1 → 人物面部、发型、年龄感
    @图片2 → 服装版型与颜色
    @图片3 → 场景布局与光源位置
    @视频1 → 摄影机运动和剪辑节奏
    @视频2 → 主动作的速度与身体重心
    @音频1 → 配乐节奏和情绪曲线
