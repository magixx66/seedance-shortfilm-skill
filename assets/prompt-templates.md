# Prompt templates

为避免元指令污染生成画面，**每镜输出必须拆为两部分**：
1. **Shot Card（导演控制卡）**：给导演/后期看的管理信息（编号、Handles、槽位映射、Shot Delta、出入状态、约束）。
2. **Copy-ready Prompt（纯生成提示词）**：可直接整段复制进 Seedance 输入框的干净自然语言（默认全中文，严格按主体→动作→环境→景别运镜→光色→声音→身体反应→槽位引用→画面约束排序，**不含 `【Shot Delta】`、`【接力】` 等管理标签**）。

---

## 1. 逻辑资产表与单镜槽位映射

项目先给资产分配**逻辑 ID**，每镜提交时再绑定该镜实际上传的**平台槽位**：

    【逻辑资产清单】
    CHAR_01：林夏（面部/发型参考图、声线说明）
    LOC_01：老站台二号站台（场景参考图）
    CAM_01：慢速侧跟拍参考片段（运镜参考视频）

    【单镜槽位映射示例（S01-02）】
    @图片1 = CHAR_01_identity.png（只参考面部与发型）
    @图片2 = S01-01_last_frame.png（只参考停步后湿发状态、光向与朝右视线）
    （若目标平台不支持 `@图片1` 内联标签，而是通过表单/API 独立槽位传入，则按 system-constraints.md 改为自然文字指代并把素材填入对应槽位）

## 2. 单镜头标准模板（Shot Card + Copy-ready Prompt）

### Shot Card｜`[S01-01]`

    【剧情目的】[本镜推演什么信息或情绪]

    【状态接力】入口：[上一镜结束状态] → 出口：[本镜结束状态，交接给下一镜]
    【生成风险约束】[只写 1–3 条高风险限制]

### Copy-ready Prompt｜`[S01-01]`

```text
[主体与逻辑形象描述] 在 [具体环境与空间方位] 完成 [一个明确主动作，留出首尾微停余量]。
[景别与构图安全区]，[一个主运镜，含方向、速度和终点]。
[光源、方向、明暗对比、色温与整体色彩质感]。

人物通过 [可见的眼神、呼吸、肩膀或手部反应] 流露情绪。
参考 @图片1 的 [指定属性]，保持 [固定服饰/道具手别/屏幕方向/光向一致]，画面中不出现多余路人、字幕或水印。
```

## 3. 15 秒连续长镜头时间轴模板（谨慎使用）

> **适用护栏**：仅在目标模型明确支持 12–15 秒单次连续叙事、且剧情确实需要**一镜到底连续调度**时使用；每段切片最多安排 1 个核心动作推进，**禁止用时间轴模板硬塞多次硬切或相互冲突的运镜**。能够拆成 2–3 个 5 秒短镜头的，优先拆镜。

### Shot Card｜`[S01-01_long]`

    【总时长与画幅】15 秒｜[画幅]｜首尾各留 ~0.5s 剪辑余量
    【参考槽位映射】@图片1 = ... ；@视频1 = ...
    【Scene Lock 引用】[场次号]
    【段间连续性要求】[人物移动轨迹与机位平滑衔接说明]

### Copy-ready Prompt｜`[S01-01_long]`

```text
[总体场景、主体与写实视觉基调]。
00:00–00:05：[景别与起点构图]，[主体第一阶段动作]，[摄影机连续运动起点]，[声音变化]。
00:05–00:10：[机位顺滑过渡到新构图]，[主体第二阶段动作与反应]，[光线或空间揭示]，[声音过渡]。
00:10–00:15：[最终定格构图]，[动作收束与段末静止状态]，[声音收尾]。
整体保持 [主光方向、色温、服装道具手别与人物面容一致]，参考 @图片1 的人物身份，不出现文字或无关人物。
```

## 5. 双镜接力完整示例（雨夜车站 `S01-01` → `S01-02`）

> 继承 `assets/continuity-lock-template.md` 第 7 节的 `Project Bible` 与 `Scene Lock｜S01`。

### 镜头 `S01-01`

**Shot Card｜`S01-01`**

    【时长与余量】5 秒｜16:9｜入画缓冲 0–0.5s，主动作 0.5–4.3s，定格余量 4.3–5.0s
    【剧情目的】建立雨夜空旷站台环境，交代林夏警觉停步的转折。
    【槽位映射】
    - @图片1 = CHAR_01_identity.png（只参考人物五官、短黑发与米色风衣/深蓝围巾造型）
    - @图片2 = LOC_01_platform.png（只参考二号站台布局、左侧长椅位置与头顶灯位）
    【Shot Delta】CHAR_01 从画面左侧向右走入至长椅前停步，转头望向右侧站台尽头；中全景缓慢侧跟拍至停稳。
    【状态接力】入口：开场建立 → 出口：停于画面中央偏左长椅前，面向并盯住右侧尽头，右手握透明伞。

**Copy-ready Prompt｜`S01-01`**

```text
写实电影摄影质感，16:9 横画幅。参考 @图片1 形象的 28 岁短黑发女性身穿米色旧风衣和深蓝围巾、右手握着透明长柄雨伞，在参考 @图片2 的夜晚老火车站二号站台积水地面上，从画面左侧稳步走向右侧，在站台长椅前突然停下脚步并转头望向画面右侧尽头，停步后维持稳定凝望至镜头结束。中全景平视构图，摄影机以缓慢平稳的侧向跟拍随她向右移动，并在她停步同时缓缓停稳。头顶偏左的冷白日光灯照亮湿润伞面与风衣肩线，右后方远处微弱橙色信号灯在湿滑地面投下暖色倒影，整体呈低饱和蓝灰冷调。环境底噪为持续均匀的雨打雨棚声与遥远模糊广播，湿地面脚步声在第 3 秒骤停，随即广播声压低、只留清晰雨滴落伞声，无配乐与对白。她停步瞬间肩膀微绷、握伞右手手指略收紧，以克制停顿显露意外与警觉。保持站台空旷无其他行人、右手握伞不变、画面无任何站牌文字与水印。
```

### 镜头 `S01-02`

**Shot Card｜`S01-02`**

    【时长与余量】4 秒｜16:9｜入画呼吸 0–0.5s，台词与反应 0.5–3.2s，尾音静默余量 3.2–4.0s
    【剧情目的】近景承接视线，用短台词点破重逢悬念。
    【槽位映射】
    - @图片1 = CHAR_01_identity.png（锁定同一面部五官与湿发细节）
    - @图片2 = S01-01_last_frame.png（只参考停步后的左上方冷白光向、微湿发梢与朝右视线角度，不复制中全景构图）
    【Shot Delta】景别切为中近景偏左构图（右侧留出视线空间），极慢推进；人物呼吸微滞后极轻说出一句 5 字短台词。
    【状态接力】入口：承接 S01-01 出口的右侧视线与右手握伞 → 出口：目光仍锁定右侧，留半秒静默切入下一镜主观视角。

**Copy-ready Prompt｜`S01-02`**

```text
延续写实电影摄影质感，16:9 横画幅。参考 @图片1 形象与 @图片2 光线视线角度的同一短黑发女性站在夜晚小雨站台长椅旁，维持身体朝右、目光紧盯画面右侧站台尽头，呼吸短暂一滞后嘴唇微动，极轻地呼出一口白气并用低缓语气轻声说：“……怎么会是你。”，说完维持凝望与静默至镜头末尾。中近景，人物置于画面左侧三分之一处留出右侧视线空间，摄影机极缓慢平滑推进。站台左上方冷白顶灯照亮她半边脸颊与微湿发梢，右后方虚化背景里可见远处橙色信号灯柔和光斑，低饱和蓝灰冷调与湿润皮肤质感保持一致。环境雨声退为轻柔背景底噪，伴随轻微风衣布料摩擦声与低轻人声台词，说完台词后保留半秒唯余雨声的留白，无配乐。她眉眼微颤却没有挪开视线，保持左上方冷白主光与右手握伞局部构图，画面无字幕与多余人物。
```
