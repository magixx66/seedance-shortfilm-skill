# Qisheng Seedance Director

这是一个面向 Seedance AI 短片与短剧的 Codex Skill。它把创意、事实核查、分镜、参考素材、人物一致性、运镜、灯光、声音和失败修复组织成可直接执行的生成方案。

## 适合做什么

- 单镜头或 15 秒 AI 电影提示词
- 60–90 秒多镜头 AI 短剧
- 历史题材的事实边界与戏剧化处理
- 人物、服装、场景和道具一致性
- 首尾帧衔接与分镜连续性
- 参考图片、视频、音频的职责分配
- 失败镜头的原因诊断与最小修改

## 使用方式

可以直接说：

- 用我的 Seedance Skill，把雨夜车站重逢短片的第一幕做出来。
- 把这个镜头改成一个主动作和一个主运镜。
- 只参考 @视频1 的运镜，不参考人物和场景。
- 人物第二镜漂移了，帮我诊断并重写提示词。

也可以显式调用 $qisheng-seedance-director。

## 核心规则

- 一个镜头，一个主动作，一个主运镜。
- 抽象情绪必须改写成可见的身体反应。
- 每个参考素材必须写清参考什么。
- 多镜头先建人物与资产清单，再写提示词。
- 平台规格会变化，真正生成前必须核对当前限制。

仓库可以命名为 seedance-shortfilm-skill，安装目录应保持为 qisheng-seedance-director，以匹配 Skill 名称。
