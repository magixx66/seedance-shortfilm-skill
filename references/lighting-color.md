# Lighting and color

灯光先解释空间和时间，再承担情绪。避免只写 cinematic lighting；写清光源、方向、软硬、色温、对比和环境介质。

## 五个维度

1. **光源**：太阳、窗光、煤油灯、路灯、屏幕、火光。
2. **方向**：顺光、侧光、逆光、顶光、下方反射光。
3. **质感**：柔和、硬朗、漫射、闪烁、被烟尘散射。
4. **明暗关系**：高调、低调、高反差、压低黑位、保留暗部细节。
5. **色彩逻辑**：主色、辅助色、强调色，以及跨镜头保持不变的规则。

## 时代或时空对照示例

### 1931 段落

- 低饱和灰褐色为主。
- 煤油灯形成局部暖光，夜晚环境是冷蓝色。
- 烟尘降低远处对比度。
- 适量 35mm 胶片颗粒与轻微曝光波动。
- 暖光只照亮人物的一部分脸，保留危险与不确定感。

### 当代段落

- 自然光和现代真实色彩。
- 画面干净，动态范围较高。
- 摄影稳定，肤色自然。
- 可保留同一个强调色或构图元素，让两个时代产生联系。

## 情绪到可执行灯光

| 抽象要求 | 可执行描述 |
|---|---|
| 不安 | 冷色环境光，走廊尽头单一暖灯，人物经过时脸部短暂进入阴影 |
| 回忆 | 窗侧柔光，低对比，背景轻微雾化，暖色高光受控 |
| 压迫 | 顶部硬光，眼窝加深，背景亮度低于人物一档 |
| 希望 | 逆光逐渐增强，阴影中出现暖色细节，整体饱和度轻微回升 |

## 跨镜头锁定

记录并重复：时间、天气、主光方向、色温、曝光倾向、主色和强调色。若剧情发生变化，明确写出变化从哪一镜开始以及原因。
