# Failures and fixes

先找最主要的问题，再做最小修改。一次改一个变量，保留已经成功的内容。

| 现象 | 常见原因 | 优先修复 |
|---|---|---|
| 人物长相、年龄或衣服漂移 | 参考职责不清，描述变化，镜头过长 | 固定角色圣经；声明参考职责；缩短镜头 |
| 手脚或肢体异常 | 同时动作过多，遮挡复杂，多人交互过密 | 只保留一个主动作；减少人物；拆镜头 |
| 镜头乱飞 | 同时要求推进、环绕、升降、拉远 | 只留一个主运镜，写清起点、终点和速度 |
| 剧情没执行完 | 时长装不下动作链 | 缩短动作或拆成多个镜头 |
| 画面“有质感词但不电影” | 缺少光源、层次和构图逻辑 | 先补光源方向、明暗关系、景别和空间层次 |
| 表演僵硬或情绪虚假 | 只写“害怕、悲伤、震惊” | 改成视线、呼吸、肌肉、姿势和物件反应 |
| 空间跳变 | 没有建立镜头或入口/出口状态 | 先交代布局；锁定门窗、方位、屏幕方向 |
| 两镜接不上 | 上一镜退出状态与下一镜入口不一致 | 记录尾帧；匹配动作、视线、声音或构图 |
| 参考视频带入错误人物或场景 | 只写“参考视频” | 限定只参考运镜、动作或节奏，并排除其他内容 |
| 声音拥挤 | 环境、音效、音乐同时争抢 | 确定声音主角；删去一层；使用短暂静音 |

## 抽象情绪改写

不要只写“他很害怕”。改写为：

    他先看向声音传来的方向，呼吸突然停住，肩膀僵硬，右手松开，手中的搪瓷杯掉在地上。

这仍可能包含太多连续动作。短镜头可进一步拆为：

    近景。他听见警报后猛地看向窗外，呼吸停住，肩膀僵硬。摄影机非常缓慢地推进。

下一镜再表现杯子落地。

## 迭代记录

每轮记录：版本、失败现象、保持项、唯一修改项和结果。连续两轮出现相同问题时，不要继续堆提示词；改用缩短时长、拆镜、换参考、固定机位或后期合成。
