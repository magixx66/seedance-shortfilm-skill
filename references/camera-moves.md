# Camera moves

先确定观众需要看见什么、感受什么，再选运镜。一个镜头只保留一个主运镜；轻微跟焦、稳定修正与自然呼吸感不算第二个主运镜。

**默认中文 Prompt 使用下表“推荐中文写法”**；仅当用户要求全英文输出或目标平台对英文术语更稳定时，使用括号内英文对应词。

| 叙事目的 | 推荐中文写法（英文对应） | 常用景别 | 注意事项 |
|---|---|---|---|
| 靠近人物内心、揭示细节 | 极缓慢推进（very slow push-in） | 中近景、特写 | 速度要慢，人物动作保持克制 |
| 跟随人物移动 | 缓慢平稳侧跟拍 / 后跟拍（slow tracking shot） | 中景、全景 | 写清起点、终点与屏幕移动方向 |
| 从人物扩展到环境 | 缓慢拉远（slow pull-back） | 中景到大全景 | 用于揭示孤独、规模或后果 |
| 紧张、临场、纪录感 | 克制轻微手持跟拍（restrained handheld） | 中近景 | 控制抖动幅度，避免混乱晃动 |
| 揭示宏大空间或孤立感 | 缓慢升起揭示（slow crane-up / aerial reveal） | 全景、大全景 | 只在空间信息对剧情关键时使用 |
| 压迫、力量、威胁 | 低机位固定仰拍（low-angle locked shot） | 中景、近景 | 低机位本身即可压迫，不必叠加环绕 |
| 搜索、扫视、发现 | 缓慢水平摇摄（slow pan） | 中景、全景 | 给出清楚起幅位置与落幅终点 |
| 主观沉浸 | 第一人称主观视角（first-person POV） | 依动作而定 | 明确视线高度、前景手部与路径 |
| 稳定对话与反应 | 固定机位 / 极轻微滑轨平移（locked-off / subtle slider） | 双人中景、过肩 | 让表演与台词承担信息，不抢戏 |

## 选择顺序

1. 写出本镜叙事目的。
2. 选景别（交代环境、关系还是表情）。
3. 选唯一主运镜；若静止更抓人，优先固定机位。
4. 写清方向、速度、起点与终点。
5. 检查人物运动与摄影机运动是否互相打架。

## 过载镜头的拆法

原始要求：人物冲出房间，镜头推进、环绕、拉远，远处爆炸，人群奔跑。

拆成三镜：

1. `S01-01` 室内中景：后跟拍人物冲向门口。
2. `S01-02` 室外大全景：固定机位看人物冲入街道，远处闪光爆发。
3. `S01-03` 室外全景：缓慢拉远，揭示混乱人群与环境后果。

## 连续性检查

- 人物上一镜向画面右侧离开，下一镜通常从左侧进入并继续向右。
- 推进特写后切大全景，用声音跨切或动作点连接。
- 主观视角前后必须建立“谁在看、看见什么、看后如何反应”。
