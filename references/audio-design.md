# Audio design

声音按四层设计。每层都可以写“无”，刻意留白比堆满声音更有力量。

## 四层模型

1. **Ambient**：持续存在的空间底噪，如风、远处交通、房间电流、雨声。
2. **Foreground SFX**：与画面动作同步的近景声，如脚步、布料、杯子落地、门轴。
3. **Music**：配乐的进入、退出、情绪、配器和强弱变化。
4. **Silence**：主动压低或移除某些声音，让一个关键声响突出。

## 写法模板

    Ambient：
    Foreground SFX：
    Dialogue / Voice：

## 示例：雨夜车站开场

    Ambient：黑屏中先出现稳定雨声和很远的车站广播。
    Foreground SFX：手机铃声从近处响起，带有空旷候车厅的反射。
    Dialogue / Voice：无。
    Music：无。
    Silence：第 3 秒压低雨声和广播，只保留手机铃声。
    Transition：铃声跨切进入下一镜，画面出现后仍持续半秒。

## 原则

- 关键动作只配一个清楚的同步声，不要给每个小动作都加效果。
- 对话镜头先保证口型、停顿和呼吸，再考虑配乐。
- 让声音承担转场：先听后见、声画错位、尾音跨切都能连接镜头。
- 需要精确节奏、歌词或版权音乐时，优先在后期加入，不依赖模型一次生成准确结果。
