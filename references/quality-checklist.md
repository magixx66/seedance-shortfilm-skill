# Quality checklist

## 故事与事实

- [ ] 每个镜头都有明确的剧情目的。
- [ ] 开场、转折和结尾能用一句话说清。
- [ ] 历史或现实信息已经核实，虚构和重构已标明。
- [ ] 总时长等于目标时长，时间轴没有重叠或空档。

## 镜头可生成性

- [ ] 每镜只有一个主动作。
- [ ] 每镜只有一个主运镜，或明确固定机位。
- [ ] 景别、构图、运动方向、速度和终点清楚。
- [ ] 抽象情绪已经改成可见表演。
- [ ] 复杂事件已经拆镜，而不是堆进一个提示词。
- [ ] 每张静态分镜图只包含一个能够被照片表现的瞬间。

## 分镜空间语法

- [ ] 对话或对峙镜头保持清楚的 180 度轴线。
- [ ] 人物视线与下一镜被观察对象的位置匹配。
- [ ] 跨镜头动作从同一动作阶段继续。
- [ ] 人物移动方向、入口和出口没有无理由反转。
- [ ] 每个分镜都增加新信息、关系变化或情绪推进。

## 图片预制作

- [ ] 已确定哪些资产需要实际生成，哪些只需要 Prompt。
- [ ] 角色、服装、道具、场景和关键帧按照依赖顺序制作。
- [ ] 不同资产分别生成，没有把过多职责挤进一张图。
- [ ] 图片编辑明确区分“只修改”和“必须保持”。
- [ ] 项目使用的最终图片已保存到项目目录并记录版本。

## 参考与连续性

- [ ] 每个 @参考 都写明参考属性。
- [ ] 人物外貌、年龄、发型、服装、道具和声线已锁定。
- [ ] 场景布局、时间、天气、光向和主色已锁定。
- [ ] 项目级 Continuity Lock 在相邻镜头中保持一致。
- [ ] 每镜只通过 Shot Delta 改变必要的动作、机位和状态。
- [ ] 上一镜退出状态与下一镜入口状态一致。
- [ ] 屏幕方向、视线和动作阶段连续。

## 灯光与声音

- [ ] 灯光写明光源、方向、质感、色温和明暗关系。
- [ ] 色彩变化有剧情理由。
- [ ] Ambient、Foreground SFX、Music、Silence 已分别考虑。
- [ ] 关键声响不会被音乐和环境声淹没。

## 平台与交付

- [ ] 实际生成前已核对当前模型、时长、画幅、输入和政策限制。
- [ ] 精确文字、字幕、日期和标牌已安排到后期。
- [ ] 参考素材具备使用权或用户已获授权。
- [ ] 没有任何规避审核、身份保护或安全过滤的做法。
- [ ] 输出包含生成顺序、命名方式和失败后的最小修复路径。
