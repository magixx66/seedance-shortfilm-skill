# Quality checklist

## 故事、事实与年代边界

- [ ] 每个镜头（`S01-01`）都有明确的剧情目的，不重复前镜信息。
- [ ] 开场、转折和结尾能用一句话说清。
- [ ] 历史或现实信息已核实，虚构与重构已标明。
- [ ] 年代/历史题材已排查现代穿帮风险（现代 LED 冷光、地面标线、现代窗框或合成面料）。
- [ ] 净剪辑总时长等于目标时长，时间轴无重叠或空档。

## 镜头可生成性与格式分离

- [ ] **Shot Card 与 Copy-ready Prompt 已明确分离**；纯提示词内无 `【Shot Delta】`、`【接力】` 等元指令标签残留。
- [ ] Copy-ready Prompt 语言统一（默认全中文自然语言，无无故中英术语混杂）。
- [ ] 每镜只有一个主动作、一个主运镜（或明确固定机位），且首尾各留约 `0.5s` 剪辑余量（Handles）。
- [ ] 抽象情绪已转成可见的视线、呼吸、肌肉或手部反应。
- [ ] 15 秒时间轴模板仅用于连续调度（未塞入多次硬切或矛盾运镜）。
- [ ] 每张静态分镜图/首尾帧只包含一个可拍瞬间；若同时使用首尾帧，两帧朝向、光向与跨度可物理衔接。
- [ ] 单镜头对白控制在时长可容纳字数内且只让一人开口；长独白或旁白已转后期。
- [ ] 9:16 竖屏项目已避让顶部 15% 标题区、底部 25% 字幕区与右侧交互区，且前 3 秒具备开场钩子。

## 分镜空间语法

- [ ] 对话或对峙保持清楚的 180° 轴线。
- [ ] 人物视线与下一镜被观察对象位置对应。
- [ ] 跨镜头动作从同一动作阶段与手别继续；移动方向无无理由反转。

## 三层连续性与资产映射

- [ ] 已分配逻辑资产 ID（`CHAR_01`、`LOC_01`、`PROP_01`），与单镜上传槽位（`@图片1`、`@视频1`）清晰分离。
- [ ] 每个槽位参考都写明参考属性与不参考属性。
- [ ] `Project Bible`（全片）→ `Scene Lock`（单场）→ `Shot Delta`（单镜）三层继承清楚，跨场换景未硬锁死前场天气/光向。
- [ ] 上一镜退出状态与下一镜入口状态一致。

## 图片预制作

- [ ] 已区分哪些资产需要生成图片、哪些仅需 Prompt。
- [ ] 不同资产独立生成，未把过多角色/景别挤进一张图。
- [ ] 图片编辑严格区分“只修改 / 必须保持 / 避免”。
- [ ] 最终图片按 `S01-01` / `CHAR_01` 规范命名并保存进项目目录。

## 灯光、声音与后期交接

- [ ] 灯光写明光源、方向、质感、色温和明暗关系；色彩变化有剧情理由。
- [ ] Ambient、Foreground SFX、Dialogue/Voice、Music、Silence 已分别设计，关键声响不被淹没。
- [ ] 精确文字、字幕、日期和复杂配乐已交由后期，并附有后期与剪辑交接表（净用区间、J/L-cut、字幕文案、调色基线）。

## 平台与合规

- [ ] 实际生成前已填写 `system-constraints.md` 核对记录卡（含模型版本、时长、参考绑定语法）。
- [ ] 参考素材具备授权；没有任何规避审核、身份保护或安全过滤的内容。
- [ ] 输出包含生成顺序与失败后的最小单变量修复路径。
