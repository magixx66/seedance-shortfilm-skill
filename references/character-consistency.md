# Character and scene consistency

多镜头项目先建立资产表与三层锁定，再写任何镜头。跨场次时继承同一份 `Project Bible`，仅更新新场次的 `Scene Lock`，绝不在每个镜头重新发明一套近义词。

## 逻辑资产表（与槽位解耦）

先为所有资产分配**项目级逻辑 ID**，避免上传顺序变化造成编号错乱：

- 人物：`CHAR_01`、`CHAR_02`（固定年龄段、脸型、五官、肤色、发型、体态、声线与口音）；
- 场景：`LOC_01`、`LOC_02`（固定空间布局、门窗出入口、标志物与时代年代特征）；
- 道具：`PROP_01`、`PROP_02`（固定比例、材质、磨损度与持握惯用手别）；
- 运镜/节奏参考：`CAM_REF_01`、`AUDIO_REF_01`。

## 单镜槽位映射与参考职责

提交单个镜头时，再把本镜用到的逻辑资产映射到平台输入槽位（如 `@图片1`、`@视频1`、`@音频1`），并在提示词或槽位说明中写清“参考什么、不参考什么”：

    @图片1 = CHAR_01_identity.png → 只参考人物面部、发型与年龄感，不复制其正面站姿。
    @图片2 = CHAR_01_wardrobe_S01.png → 只参考本场服装版型与颜色，不参考人物长相。
    @图片3 = LOC_01_establishing.png → 只参考场景布局、年代细节与光源位置。
    @视频1 = CAM_REF_01.mp4 → 只参考摄影机运动与节奏，不复制视频内人物与场景。
    @音频1 = AUDIO_REF_01.wav → 只参考配乐节奏与情绪曲线，不复制原人声或歌词。

## 镜头间接力

1. 在 Shot Card 记录上一镜的退出状态：位置、朝向、视线、动作阶段、表情、道具手别与光线。
2. 下一镜从相同状态开始，只推进一个 `Shot Delta` 变化。
3. 可用上一镜尾帧作为下一镜参考图，但仍须在 Copy-ready Prompt 中用文字重申需保持的核心要素。
4. 如果人物持续漂移，先缩短镜头时长、减少同框人数、简化动作，再叠加参考图约束。

## 多人镜头

- 给每个人固定逻辑编号（`CHAR_01` / `CHAR_02`）和左右站位。
- 明确谁在前景、谁在背景、谁先动作、谁朝向谁说话。
- 群像若不稳定，拆成建立镜头、单人反应和双人过肩关系镜头。

## 场景与年代连续性

锁定房间布局、门窗出入口、关键道具、时间天气、主光方向、空气介质与地面状态。历史或年代题材额外锁定：**禁用现代照明（如冷白 LED）、现代地面标线、现代窗框或现代合成面料光泽**，防止 AI 自动补出穿帮元素。
