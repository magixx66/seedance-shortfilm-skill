# Storyboard grammar

分镜首先要让观众看懂空间、动作和情绪，再追求漂亮画面。每一格描述一个可以被摄影机清楚捕捉的瞬间。

## 单一瞬间规则

静态分镜图必须能够由一张照片表现。一个描述如果需要“先、然后、最后”才能成立，就应该拆成多格。

不适合单格：

    她转身认出对方，然后跑过去拥抱他。

拆成：

1. 她停在站台中央，回头看向画面右侧。
2. 久别的人站在站台尽头，手里握着旧照片。
3. 她向对方奔跑，外套下摆向后扬起。
4. 两人在站台中央拥抱。

静态分镜写“可见状态”；视频 Prompt 再写动作如何发生、摄影机如何移动以及镜头结束在哪里。

## 180 度轴线

两个人或人物与目标物之间存在一条关系轴。连续对话或对峙镜头尽量把摄影机放在轴线同一侧，使人物在画面中的左右关系保持稳定。

只有以下情况适合跨轴：

- 用正面中性镜头重新建立方向；
- 摄影机在画面中连续移动并清楚越过轴线；
- 剧情需要刻意制造迷失感，而且观众仍能理解空间。

## 视线匹配

人物看向某处时，下一镜中的对象位置应与视线方向对应。

记录：

- 人物位于画面哪一侧；
- 视线向左、向右、向上或向下；
- 对象距离与高度；
- 下一镜是人物主观视角，还是客观反打。

## 动作匹配

跨镜头拆分一个动作时，下一镜从相同动作阶段继续。

示例：

- 镜头 A：中景，手伸向门把手；
- 镜头 B：特写，同一只手在相同方向握住门把手；
- 镜头 C：室内反打，门从对应方向打开。

不要让道具换手、动作重置或身体朝向突然改变。

## 屏幕方向

人物向画面右侧移动，下一镜通常继续向右。若必须改变方向，先表现人物转身、路线变化或中性正面镜头。

多人场景记录：

- 谁位于画面左、中、右；
- 谁更靠近摄影机；
- 入口和出口位置；
- 关键道具的空间位置；
- 主光方向和背景标志物。

## 建立、发展与反应

常见镜头功能：

1. 建立镜头：交代地点、人物关系和行动路线。
2. 动作镜头：推进一个主要行为。
3. 插入镜头：强调道具、手部或关键信息。
4. 反应镜头：表现事件对人物造成的可见影响。
5. 结果镜头：交代动作后的新状态。

不要为了镜头数量重复同一信息。每个镜头必须增加新信息、改变关系或推进情绪。

## 分镜记录格式

| 字段 | 内容 |
|---|---|
| Scene / Shot | 场次与镜头编号 |
| Story beat | 本镜头推进什么 |
| Framing | 景别、角度、构图 |
| Visible moment | 一张静态画面能够表现的瞬间 |
| Motion plan | 视频阶段的主体动作与主运镜 |
| Duration | 预计时长 |
| Entry state | 人物、道具和摄影机的开始状态 |
| Exit state | 镜头结束状态 |
| Continuity cue | 轴线、视线、屏幕方向、光向或动作接力 |
| Sound | 环境、动作、对白、音乐或静音 |

## 检查顺序

1. 不看原剧本，只看分镜能否理解故事。
2. 检查每格是否是单一可见瞬间。
3. 检查人物左右关系、视线和移动方向。
4. 检查道具、服装、天气和光线。
5. 检查相邻镜头是否通过动作、视线、构图或声音连接。
6. 删除只重复姿势、景别或信息的镜头。
