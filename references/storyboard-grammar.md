# Storyboard grammar

分镜首先要让观众看懂空间、动作与情绪，再追求漂亮画面。每镜统一使用场次+镜头编号（如 `S01-01`、`S01-02`；单场戏默认为 `S01`）。

## 单一瞬间规则（静帧/首帧）

静态分镜图或首尾帧必须能由一张照片表现。需要“先、然后、最后”才能成立的描述必须拆镜。

- 不适合单格：`她转身认出对方，然后跑过去拥抱他。`
- 拆成：`1. 站台中央回头看向右侧` → `2. 对方站在尽头手握旧照片` → `3. 她向对方奔跑` → `4. 两人拥抱`。

静态分镜写“可见瞬间”；视频 Prompt 再写动作如何发生、摄影机如何移动以及镜头定格在哪里。

## 剪辑余量（Handles）与时间轴护栏

- **剪辑余量（Handles）**：每镜首尾各留约 `0.5s` 的自然入画缓冲与定格余量。例如 5 秒镜头，核心主动作与台词控制在 `0.5s–4.3s` 完成，避免动作刚起或话没说完就被切掉，方便后期做叠化或 J/L-cut。
- **15 秒时间轴模板护栏**：仅在目标模型明确支持单次长段叙事、且需要连续一镜到底调度时启用；每个时间切片最多推进一个动作变化，禁止硬塞多次硬切或矛盾运镜。能拆成多个 4–8 秒短镜头时，优先拆镜。

## 9:16 竖屏短剧构图与节奏

当项目画幅为 `9:16` 竖屏时，遵守以下调整：

- **上下左右安全区**：顶部约 15% 避让标题/状态栏，底部约 20–25% 留给台词字幕与平台按钮，右侧边缘留出交互图标余量；人物眼睛尽量落在画面中上三分之一交界处。
- **景别与走位收紧**：优先中景、中近景与特写，少用超宽横向全景；人物横穿画面距离受限时，改用纵深前后走位、转身朝向或微幅度侧移替代长距离横摇。
- **黄金前三秒**：首镜（`S01-01`）尽快给出冲突动作中段、异常声响或悬念特写，不在开场浪费 5 秒慢摇空镜。

## 180 度轴线与视线、动作匹配

- **180 度轴线**：连续对话或对峙将摄影机保持在关系轴同一侧，维持左右站位不变；仅在正面中性过渡镜、连续移动越轴或刻意制造迷失感时跨轴。
- **视线匹配**：明确人物在画面左/右侧及视线朝向（左/右/上/下），下一镜被看对象的位置与高度须与之呼应。
- **动作匹配**：跨镜拆分同一动作时（如伸手→握把手→门开），下一镜从上一镜结束时的手别、朝向与动作阶段无缝延续。
- **屏幕方向**：上一镜向画面右侧离开，下一镜通常从左侧进入并继续向右；反向移动前先给转身或正面中性镜。

## 分镜记录字段

| 字段 | 内容 |
|---|---|
| Scene / Shot | `S01-01` 编号 |
| Story beat | 本镜推进的剧情/关系/情绪变化 |
| Framing | 画幅、景别、角度与安全区构图 |
| Visible moment | 单张静帧可捕捉的瞬间 |
| Motion plan | 视频阶段唯一主动作与唯一主运镜 |
| Duration (Handles) | 总时长及有效动作区间（如 `5s｜0.5–4.3s`） |
| Entry → Exit state | 开始状态 → 结束状态 |
| Continuity cue | 轴线、视线、屏幕方向、光向或动作接力 |
| Sound | 环境、动作、台词、配乐或留白 |

## 自检顺序

1. 遮住文学剧本，只看分镜表能否看懂因果与转折。
2. 检查每张静帧是否只含一个可拍瞬间。
3. 检查 180° 轴线、人物左右关系、视线与移动方向是否一致。
4. 检查每镜是否预留首尾余量（Handles），竖屏项目是否避让字幕安全区。
5. 删除只重复前镜信息、没有新推进的冗余镜头。
