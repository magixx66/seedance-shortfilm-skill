# Image preproduction workflow

图片预制作把文字故事转成可复用的视觉资产，再用于分镜图、首尾帧和视频生成。用户只要提示词时，输出计划与提示词；用户明确要求生成图片时，调用当前客户端可用的内置生图工具（如 `imagegen` / `image-generator`）。

## 何时使用

适合：

- 多镜头短片需要固定人物、服装和场景；
- 用户需要人物设定图、场景图、道具图或镜头首尾帧；
- 直接文生视频出现人物漂移或空间跳变；
- 用户希望先看视觉方向，再投入视频生成。

简单单镜头、抽象动态测试或已有完整参考素材时，可以跳过部分步骤。

## 三阶段生产链

### 阶段一：设计设定板

建立项目的视觉词典：

- 角色：正面、四分之三侧面、侧面、全身、关键表情；
- 服装：完整造型、材质、颜色、鞋、饰品；
- 道具：比例、磨损、颜色和使用方式；
- 场景：建立视角、平面关系、入口出口、主要光源；
- 风格：色板、对比度、质感和真实感规则。

优先分别生成清晰资产，不要把所有信息挤进一张复杂拼贴图。设定板用于概览时，可以制作网格；身份敏感的正式参考图仍应保留独立文件。

### 阶段二：静态分镜与关键帧

先写镜头表，再为每镜选择：

- 单独分镜图；
- 视频首帧；
- 必要时的视频尾帧；
- 仅用于构图、灯光或动作的参考图。

每张静态图只表现一个可拍摄瞬间。遵循 [storyboard-grammar.md](storyboard-grammar.md)。

### 阶段三：从图片进入视频

1. 选择通过检查的角色、场景和首帧资产。
2. 在逻辑资产表固定项目级 ID（如 `CHAR_01`、`LOC_01`、`S01-01_first_frame`）。
3. 在 Shot Card 中映射本镜上传槽位（如 `@图片1 = CHAR_01_identity.png`），写明每张图负责什么、不负责什么。
4. 在 Copy-ready Prompt 中自然融入视觉描述与槽位指代，保持三层连续性一致。
5. 只描述从首帧开始的动作、主运镜和结束状态。
6. 视频成功后保存尾帧、Prompt 和参数，用于下一镜接力。

## 使用内置生图工具

用户明确要求实际生成或编辑图片时：

1. 默认使用当前客户端可用的内置生图工具（如 `imagegen` / `image-generator`），不要求用户提供 API Key。
2. 新图生成：为每个不同资产使用独立 Prompt 和独立生成调用。
3. 参考生成：明确每张输入图片的职责。
4. 编辑本地图片：先查看图片，再提交编辑；不要凭文件名猜内容。
5. 编辑时使用“只修改 / 必须保持”结构，非破坏性保存新版本。
6. 每张图生成后检查主体、身份、构图、文字、约束和用途。
7. 一次只修正一个主要问题。
8. 项目要使用的最终图片应保存进项目目录，并报告路径；仅供讨论的预览图可以直接展示。

如果内置生图工具不可用，说明可选的显式 CLI/API 路径及其前置条件，不要私自切换。

## 首帧与首尾帧协同原则

- **只用首帧**：动作轨迹自由、结尾只需要自然停顿或跟随环境流动的镜头，单用首帧更流畅。
- **同时用首尾帧**：需要严格落点（如“手从桌面伸向门把手并停在门边”或“两镜之间精确衔接”）时使用。
- **避免物理冲突**：首尾帧之间的人物朝向、光线方向、服装道具和景别变化必须能在该镜头时长内连续完成；不要让首帧面朝左、尾帧突然面朝右且机位跳跃，否则中间帧容易扭曲或瞬移。
- **动作留白**：首尾帧只锁定“起点瞬间”和“终点瞬间”，中间路径写在视频 Prompt 中，不在静帧里叠加残影或过程动作。

## 图片 Prompt 结构

    【用途】角色参考图 / 场景参考图 / 分镜图 / 首帧 / 尾帧
    【场景】空间、时间、天气和故事线索
    【主体】身份、外貌、服装、姿势、视线和道具
    【构图】景别、角度、画幅、主体位置和留白
    【灯光】可见光源、方向、软硬、对比和色温
    【色彩与质感】主色、辅助色、真实感和材料细节
    【参考素材】每张图片的明确职责
    【Continuity Lock】不可变化的视觉事实
    【Shot Delta】本图允许发生的变化
    【文字】精确文字或明确无文字
    【避免】最可能出现的失败

## 编辑 Prompt 结构

    【只修改】
    <一个明确的视觉变化>

    【必须保持】
    <人物身份、面部、发型、姿势、身体比例、构图、摄影机角度、
    背景布局、道具、光向、画幅等不允许变化的内容>

    【避免】
    <与本次编辑最相关的失败>

## 文件与版本

统一使用场次与镜头编号命名，保留成功版本、不直接覆盖：

    CHAR_01_identity_v01.png
    CHAR_01_wardrobe_S01_v01.png
    LOC_01_establishing_S01_v01.png
    S01-01_first_frame_v01.png
    S01-01_last_frame_v01.png

资产清单记录：逻辑 ID、文件名、用途、Prompt、参考来源、版本、通过/待修改和连续性备注。

## 交付内容

图片预制作任务应返回：

1. 逻辑资产清单与生成顺序；
2. 每项资产的最终 Prompt（与 Project Bible / Scene Lock 对齐）；
3. 已生成图片的预览和路径；
4. 未通过项与最小修复建议；
5. 图片到视频单镜槽位的引用映射。

## 图片 Prompt 示例（首帧 `S01-01`）

    【用途】S01-01 视频首帧（对应 CHAR_01 + LOC_01）
    【场景】夜晚的老火车站二号站台，地面湿滑有反光，持续小雨，远处站台尽头有一盏微弱橙色信号灯。
    【主体】28 岁女性，齐耳短黑发微湿，穿米色旧风衣、深蓝围巾，右手握一把透明长柄雨伞，正从站台左侧朝右侧长椅方向迈步，视线看向前方长椅。
    【构图】16:9 横画幅，中全景，平视机位；人物位于画面左侧三分之一处，右侧留出长椅和站台延伸空间。
    【灯光】站台顶部偏左冷白日光灯为主光，在雨伞与风衣肩部打出冷色湿润轮廓光；右后方橙色信号灯在地面留微弱暖色倒影。
    【色彩与质感】低饱和蓝灰冷调与局部微暖对比，写实电影摄影质感，自然胶片暗部细节，真实雨水与布料褶皱。
    【槽位参考】@图片1（CHAR_01_identity_v01.png）：只保持面部、发型、服装版型和颜色；不复制其站立正面对视姿势。
    【保持与锁定】短黑发、米色风衣、深蓝围巾、右手透明雨伞、夜晚小雨、冷白顶灯左上方主光；人物处于迈步瞬间。
    【文字】无任何文字、站牌字样或水印。
    【避免】伞换到左手、面部失真、多余路人、站牌出现乱码文字。
